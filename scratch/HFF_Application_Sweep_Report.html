2. What Is Working Well

1. Offline-First Resilience (Dexie.js)

12-version IndexedDB schema provides reliable offline caching for registrations, participants, and notice bulletins with live reactivity across all views via useLiveQuery.

2. Comprehensive Campaign Hub

Supervisors can filter hundreds of records, inspect facilitator cohorts, record attendance across all 12 campaign days, and track educational book disbursements.

3. Automated Data Deduplication

The maintenance engine identifies duplicate participants across identical names, ages, and affiliations, combining contact details and attendance records into the most recent master entry.

4. Dedicated Facilitator Portal

Field facilitators logging in without completed onboarding are automatically guided through demographic profiles before accessing their mobile attendance sheet.

5. Two-Way Sync Architecture

Differential synchronizer compares timestamps (updated_at) to prevent pulling unchanged records, propagates soft deletes (is_deleted), and queues local offline changes.

6. Client-Side Certificate Engine

Built-in pdf-lib integration stamps formatted participant names directly onto the high-resolution certificate template and bundles qualifying attendees into ZIP files.

Issue A: Syntax Error Halts Build in SatDashboard.jsx Critical Blocker

In src/components/SatDashboard.jsx, line 225 opens a container div for the search input and export buttons, but never closes it before line 257. This leaves the outer card div unclosed, terminating the build process with error code 1.

Issue B: Supabase Environment Variable Mismatch & Inactive Host Auth & Cloud Down

1. Key Name Mismatch: .env.local contains Vercel-generated variables (NEXT_PUBLIC_hffdashboardfinal_SUPABASE_URL, hffdashboardfinal_SUPABASE_ANON_KEY), while src/lib/env.js expects VITE_SUPABASE_URL and VITE_SUPABASE_ANON_KEY. As a result, isConfigured evaluates to false.

2. DNS Unresolved: Network lookup for trirtnxcyjwdzhjmaubn.supabase.co returns ENOTFOUND, indicating that the free-tier Supabase project has been paused due to inactivity.

Resolve-DnsName : trirtnxcyjwdzhjmaubn.supabase.co : DNS name does not exist Fix: Log into supabase.com/dashboard and click "Restore Project" / "Unpause".
Issue C: Disconnected UI Controls in Dashboard.jsx User Experience Bug

1. Gender Filter Placebo: The Universal / Male / Female toggle buttons update a local state variable (genderFilter), but this value is never passed to AttendanceChart or used to filter dailyStats.

2. Dead "Download Summary" Action: In Dashboard.jsx, <ActionPanel /> is instantiated without passing an onDownload callback, leaving the prominent button completely non-functional.

3. Static Dummy Notice Board: Dashboard.jsx imports an outdated mock (NoticeBoard.jsx with fake notices like "Maun Site Visit Oct 14") instead of the live dynamic hub/NoticeBoard.jsx.

Issue D: Serverless API Schema Discrepancies Backend Warning

1. api/health.js: Attempts to query a non-existent notes table, returning a 503 Service Unavailable error on health checks.

2. api/process-registration-queue.js: Queries processed = false on the registrations table, but that column does not exist in the Supabase schema.

3. scripts/calculate_facilitator_certificates.js: Uses a relative path pointing to scripts/.env.local instead of ../.env.local.
